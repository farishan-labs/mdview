# Changelog

All notable changes to mdview are documented here.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [0.1.0] - 2026-11-14

### Added
- Initial release: native fullscreen markdown viewer (GTK3 + WebKit2 4.0).
- Table of contents sidebar, in-page search, auto light/dark theme.
- `/openmd` slash command integration (via farishan-labs/agent).
- Install/uninstall scripts served via GitHub Pages.
